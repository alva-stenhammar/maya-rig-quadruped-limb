# Rig Quadruped Limb

### This script automatically rig limbs! How neat (⁠╹⁠▽⁠╹⁠)

_**OBS!** Only works on limbs with four joints (basically quadruped rigs)._


This is a Maya script written mostly for personal use, so the naming conventions are specific to what I like to use in my rigs. You do get to choose a control suffix.

The naming convention for controls are as follows: control group = **L_shoulder_IK/FK_CTRL_GRP**, offset group = **L_shoulder_IK/FK_OFFSET_GRP**, control = **L_shoulder_IK/FK_CTRL**.

The script includes FK & IK with a switch, stretchy limbs, and some nice custom attributes.
